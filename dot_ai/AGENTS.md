# Agent Instructions Router

Router for global agent conventions. Repository conventions (a repo's AGENTS.md and docs/) override these baselines; when working in a repository, follow its docs first.

- [Writing style](~/.ai/writing-style.md): direct, concise, impersonal language rules.
- [Environment](~/.ai/environment.md): shell navigation, local notification dispatch, and review models.
- [Git conventions](~/.ai/git-conventions.md): branch, commit, and attribution conventions.
